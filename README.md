# DRET – Make Your Own Cards

DRET is a free, simple website where people pick a card design, add their own photo and text, and download the result as a PNG or PDF.

## What it does

- Several card designs, each with its own editor
- Upload your own photo, then zoom and move it
- Edit your name, details and signature (where allowed)
- Download a high-quality transparent PNG (or a PDF, for some designs)
- Everything runs in the browser. Photos are never uploaded to a server.

## Project structure

```
flex-site/
├── index.html    The whole website (one self-contained file)
├── README.md     This file
└── .gitignore    Files Git should ignore
```

The site is a single HTML file. Images, fonts and scripts are built into it, so there is nothing else to install or run.

## How to run it locally

1. Download or clone this repository.
2. Open `index.html` in any modern web browser.

No build step or server is needed.

## Deployment

The site is static, so it can be hosted for free on GitHub Pages, Netlify, Firebase Hosting or any other static host.
